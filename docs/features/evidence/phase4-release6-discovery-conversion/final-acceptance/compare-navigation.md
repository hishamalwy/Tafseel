# Compare navigation

Compare remains a 2–3 Teacher overlay on Browse (no standalone Compare document). Compare IDs are in the URL.

Accepted:

- `11-browse-compare-back` — Back from Compare restores discovery filters
- `12-compare-profile-back` — Compare → Profile → Back returns to Browse with compare + discovery query intact

Compare conversion links carry the contextual TeacherService (async Request or exact-service Book). Availability on Compare still requires summary `teacherServiceId` to match the contextual service.
