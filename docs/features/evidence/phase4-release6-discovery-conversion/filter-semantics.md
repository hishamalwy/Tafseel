# Filter semantics

- Subject and Service mean an eligible offer exists for both constraints together.
- Language means the Teacher's canonical teaching languages contain every selected ID.
- Education level uses the existing public profile association.
- Rating is the existing eligible visible-review aggregate and is absent when unsupported.
- Maximum price applies to the scoped contextual offer.
- Qualified-only retains the canonical approved-qualification meaning.

Unknown IDs produce zero results; they do not widen discovery.
