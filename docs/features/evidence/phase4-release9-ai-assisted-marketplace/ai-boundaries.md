# AI Boundaries

Allowed: interpret intent, extract named constraints, ask at most two clarifying questions, draft Student-supplied request facts, and phrase answers from approved help context.

Forbidden: Teacher IDs or ranking; eligibility, qualification, moderation, price, availability, payments, refunds, disputes, policy invention, catalog writes, request submission, tools, code execution, web search, file analysis, private Admin/Quality/Teacher data, full marketplace datasets, or autonomous actions.

Every output passes schema deserialization, bounded field checks, allowlist checks, and canonical resolution before use.
