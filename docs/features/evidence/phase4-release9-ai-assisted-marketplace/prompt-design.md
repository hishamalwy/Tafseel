# Prompt Design

Prompt version: `r9-v1`, centralized in `AiPrompts`.

All prompts label Student text as untrusted data, request only a strict schema, prohibit invented facts and privileged actions, and require the Student's language. Discovery prohibits Teacher names/ranking/IDs; request drafting prohibits new facts or submission claims; help is confined to an explicit approved context. No prompt grants tool, browsing, code, SQL, or memory access.
