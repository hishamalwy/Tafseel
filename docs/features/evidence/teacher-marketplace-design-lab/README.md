# Teacher Marketplace Design Lab Evidence

This folder records the visual exploration, refinement, responsive proof, and live production certificate for Browse Teachers and Teacher Profile.

| Folder | Contents |
|---|---|
| `concepts/` | Browse A/B/C and Profile A/B/C at desktop Arabic dark, desktop English light, and mobile Arabic light. |
| `winner/` | Browse C and Profile C refinement history, including the accepted V3 final states. |
| `responsive/` | Accepted winner across 375, 390, 768, 1024, 1280, 1440, and 1680; Arabic/English; light/dark. |
| `integration/` | Machine-readable certificate from the real production pages and live development API. |

The production pages were visually inspected live. Screenshots containing the current prominently named UAT-only teacher fixtures were not promoted into final evidence; the clean isolated winner matrix is the visual reference, while `integration/audit.json` proves real-data wiring and responsive geometry.
